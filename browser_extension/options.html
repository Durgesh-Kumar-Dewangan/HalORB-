Tray Status Indicator - Website Safety Reporter

This extension reports the active tab's safety status to the desktop tray app running on this PC.

Right-click the Tray Status Indicator icon → "Show pairing token" to get this.

Free to obtain from the Safe Browsing API docs. Without a key, the extension still flags suspicious URLs using local heuristics (IP-address links, punycode/look-alike domains, brand-impersonation patterns, risky TLDs).
